# Project 4 — General Knowledge Quiz

## 📌 Overview

This is a simple Python-based General Knowledge Quiz developed as part of my Decode Labs Python Internship.

The program asks the user three general knowledge questions, checks each answer, and calculates the final score.

## 🛠️ Technologies Used

* Python
* Conditional Statements
* User Input
* Strings
* Variables
* `if-else` statements

## ⚙️ How It Works

1. The program initializes the score to `0`.
2. The user is asked three general knowledge questions.
3. Each answer is processed using `.strip().lower()` to handle extra spaces and differences in letter case.
4. The program checks whether the answer is correct.
5. The score increases by `1` for every correct answer.
6. After all three questions, the final score is displayed.

## ▶️ How to Run

Make sure Python is installed on your computer.

Run the following command:

```bash
python general_knowledge_quiz.py
```

### Example

```text
1. What is the capital of France? Paris
Correct!

2. How many days are there in a week? 7
Correct!

3. Which planet is known as the Red Planet? Mars
Correct!

Final Score: 3 / 3
```
